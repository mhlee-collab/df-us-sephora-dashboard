# DF_US 세포라 대시보드

Dr.FORHAIR 미국(세포라) 전용 대시보드. **통합 탭 · 유입 채널 탭** 2개.

```
GitHub Pages  ──  index.html (단일 파일)
                        │ fetch  /exec?token=…
                        ▼
        Google Apps Script 웹앱  ──  Drive JSON 캐시 (30분 트리거)
                        │ 파싱
                        ▼
          구글 시트 [DF_US] 세포라 대시보드 RAW
             구분자 · RAW_commerce · RAW_유입
```

| | |
|---|---|
| Pages | https://mhlee-collab.github.io/df-us-sephora-dashboard/ |
| 접근 | Google OAuth · `@wyattcorp.com` 계정 전용 |
| Apps Script | `DF_US 대시보드 API` (RAW 시트 컨테이너 바인딩) |
| 배포 설정 | 실행: MJ 계정 / 액세스: wyattcorp.com 도메인 내 사용자 |
| 환율 | $1 = 1,500원 |

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 대시보드 전체. **단일 파일** — CSS·JS 를 분리하지 않는다 |
| `apps-script/Code.gs` | Apps Script 백엔드. 이 파일을 스크립트 편집기에 붙여넣는다 |
| `test/` | 검증 러너 — `node test/run.js` |

---

## 처음 세팅 (Apps Script)

1. `apps-script/Code.gs` 전체를 스크립트 편집기에 붙여넣고 저장
2. **시트 ID** — 컨테이너 바인딩이라 보통 그대로 돈다.
   시트를 갈아끼울 때만 `프로젝트 설정 → 스크립트 속성` 에 `SPREADSHEET_ID` 추가
   (🛑 리포지토리가 공개라 코드에 시트 ID를 박지 않는다)
3. 함수 드롭다운에서 **`checkSheet`** 실행 → 로그에 탭 3개가 `✔` 로 뜨는지 확인
4. **`setupCacheTrigger`** 실행 (최초 1회)
   · Drive 권한 승인 요청이 뜨면 승인
   · 로그에 **「캐시 갱신 완료: N bytes, N초」** 가 떠야 진짜 성공이다.
     「실행이 완료됨」만 뜬 건 성공이 아니다
5. **`checkTotals`** 실행 → 합계가 `test/README.md` 의 기대값과 맞는지 대조
6. 배포 → **배포 관리 → 연필 → 버전: 새 버전 → 배포**

## 재배포

🛑 **「배포 관리 → 연필 → 새 버전」만 쓴다.**
「새 배포」를 누르면 `/exec` 주소가 새로 발급돼 대시보드가 구버전을 계속 바라본다.
OAuth `redirect_uri` 와 Pages 호스트도 하드코딩돼 있으니 **리포지토리 이름·계정명·Pages 주소를 바꾸지 않는다.**

★ Apps Script 는 **재배포 없이도 프로덕션에 반영된다** — 30분 트리거가 저장된 최신 코드로 캐시를 굽기 때문.
단 `?only=` · `doPost` 처럼 **캐시를 안 거치는 경로는 배포된 버전의 코드로 돈다** → 그쪽을 고쳤으면 반드시 새 버전 배포.

## 엔드포인트

| 경로 | 동작 |
|---|---|
| `/exec?token=` | 현재 캐시 반환 (라이브 파싱 아님) |
| `?fresh=1` | 캐시 우회 + 라이브 파싱 + 캐시 재작성 — 사이드바 `↻ RAW` 버튼이 이걸 붙인다 |
| `?only=meta\|commerce\|channel` | 단일 섹션 경량 경로 (캐시 미경유) |

응답에 `updatedAt` · `cacheBuiltAt` · `servedFrom` 이 실려 있다. 화면 우상단에서 `servedFrom` 을 볼 수 있다.

## 시트 규칙

🛑 **열 추가는 언제나 맨 오른쪽.** 중간 삽입은 파서를 깨뜨린다.
파서는 **완전 일치 헤더명**으로만 열을 찾고, **열 개수·필수 헤더를 검증**한다.
열이 줄거나 헤더명이 바뀌면 실제 헤더 목록을 실은 에러로 즉시 멈춘다.
탭 이름 · 헤더명을 바꾸지 않는다. 값 갱신은 안전.

| 탭 | 기준 열 수 | 대시보드 키 |
|---|---|---|
| `구분자` | 9 | SKU 매핑 정본 — 조인 키는 **언제나 `Sku Number`** |
| `RAW_commerce` | 24 | 통합 탭 — 방문 · 매출 · 주문 · 전환 |
| `RAW_유입` | 17 | 유입 채널 탭 (M열은 헤더 없는 상수 1500) |

## 데이터 규칙 — 어기면 수치가 틀린다

**🛑 `NA` 채널** (방문 0 · 매출만 있는 미귀속 매출)

| 용도 | 처리 |
|---|---|
| 채널 차트 · 채널별 표 | 제외 |
| 매출 합계 · KPI | **포함** — 빼면 통합 탭과 13.6% 어긋난다 |
| 전환율 | 분모 0이라 `-`. 0으로 찍지 않는다 |
| 경고 | NA 매출 ÷ 전체 매출 > 15% 일 때만 화면에 표시 |

**⚠️ 방문 정의 차이** — `RAW_유입` 방문 < `RAW_commerce` 방문. 집계 단위가 다르다.
**방문당 매출 · 전환율은 반드시 같은 탭 안에서** 계산한다. 교차 계산 금지.

**⚠️ 그 밖**

- 값 0인 채널은 원본에서 행 자체가 빠진다 → 파서가 0으로 채워 계열이 끊기지 않게 한다
- `LY` · `YoY` 열은 전 기간 0(미국 첫 해) → 화면에서 제외
- **7/29 · 7/30 은 매출 0 · 방문 정상.** 세포라 입점일이라 정상값이다.
  결측 처리하지 않는다. 「매출 0 = 셧다운」 보정 로직을 넣지 말 것
- 전환율은 원본 `Conversion TY` 를 그대로 쓴다. 재계산하지 않는다
  (통합 탭 CVR = 주문 수량 ÷ Visits TY 는 이 값을 방문 가중 합산한 것과 **정확히 같다**)
- `년` · `월` 은 **일자 기준**으로 자른다. 주 기준으로 자르면 월 합계가 어긋난다
- `Sales 파싱` · `매출(현지 통화)` 는 UNOVE 잔재다. 파서는 참조하지 않는다
- **화면 문구에 주차 수·개수를 새로 박지 않는다.** 회차 라벨은 전부 `D.weeks` 파생

## 프런트 규칙 — 전부 실제로 터졌던 것

| 증상 | 조치 |
|---|---|
| 접기/펼치기 때 순간 렉 | `html{overflow-y:scroll}` |
| Pretendard 가 Arial 로 떨어짐 | **CSS `font:` 축약형 금지** (`font-family` 까지 덮어쓴다) |
| `Maximum call stack` | 차트 생성 후 `chart.options.plugins.tooltip.callbacks.* = fn` 대입 금지. config 안에서만 정의 |
| 0 기준선이 17~21px 뜸 | 축 `offset:true` 금지. 매출축은 `min:0` + `beginAtZero:true` |
| 새 데이터가 와도 화면이 안 바뀜 | `refreshMain(force)` · `refreshChannel(force)` — 데이터 대입 직후 강제 재렌더 |
| 리스너가 여러 벌 등록됨 | `window.__dfusDocClick` 으로 **이름 붙여** 등록 전 제거 |
| 표 우측 여백 이상 | `width:100%` + **고정 열 `width` 명시** 함께 |
| sticky 가 안 먹음 | 같은 선택자 뒤쪽에 `position:relative` 를 다시 선언하지 않는다 |
| 일 보기 x축 라벨 겹침 | 세로 · 9px |
| 구간 폭이 음수 | 「N개 구간」 계산은 N=0 을 반드시 가드 |

`node test/run.js` 가 위 규칙 대부분을 자동으로 잡는다.

⚠️ **계측 함정** — 자동화 탭이 백그라운드(visibility hidden)면 `requestAnimationFrame` · 렌더가 throttle 돼 **렉이 아예 안 잡힌다.** 렉·리사이즈 계측은 **전면 탭에서만** 유효.
⚠️ **성능 수치는 인용 전에 반드시 재측정.**

## 채널 멀티선택 표시 방식 (Dr.FORHAIR 설계 → UNOVE 역이식 예정)

UNOVE 미결 항목. 지표 3개 × 채널 N개를 3축에 한꺼번에 얹으면 축이 서로를 눌러 아무것도 안 읽힌다.

| 모드 | 동작 |
|---|---|
| **합산** | Sales(막대) + Visits(면) + CVR(선) 3축 오버레이 |
| **채널별** | 축을 하나로 고정하고 **지표를 하나만** 골라 채널 고정색 라인으로 분리 |

채널을 2개 이상 고르면 자동으로 「채널별」로 넘어가되, 사용자가 모드를 직접 누른 뒤에는 자동 전환하지 않는다.

검증 후 UNOVE 로 역이식한다. **UNOVE 리포지토리 · Apps Script · 시트에는 손대지 않는다** (읽기만 가능).
